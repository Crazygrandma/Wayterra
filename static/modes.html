Game Modes

Wayterra provides multiple modes designed for different experience levels and workflows. Each mode enables or hides features so that users can interact with the system in a way that matches their familiarity with the environment.

Lower modes focus on simplicity and guidance, while higher modes gradually introduce more freedom and customization.

Apprentice Mode

The Apprentice mode is designed for users who are familiar with traditional desktop environments such as Plasma or GNOME.

Window movement and system interaction are simplified to provide a familiar experience. Applications can be launched through an overlay using the rofi launcher.

The desktop background represents a pre-built town where buildings visually represent available applications.

Adventurer Mode

The Adventurer mode introduces the core gameplay-inspired interaction style of Wayterra.

Users are encouraged to explore the desktop world and interact with different elements to open applications, manage windows, and navigate the system.

Guide

  • Move around the world to discover applications
  • Interact with buildings to launch programs
  • Use shortcuts to quickly navigate between locations

Wizard Mode

The Wizard mode unlocks the full functionality of Wayterra.

It builds upon the Adventurer mode while providing advanced tools for customization and automation.

Users can create scripts and modify the behavior of building blocks, allowing them to extend and adapt the environment to their workflow.

Guide

  • Create scripts to automate interactions
  • Customize building behaviors
  • Extend the world with additional functionality
